V63 - GALERÍA DE IMÁGENES + ZOOM

Novedades:
- Cada producto puede tener varias imágenes.
- Al crear un producto puedes seleccionar hasta 8 imágenes de una vez.
- Desde Editar producto puedes:
  * añadir más imágenes,
  * elegir cuál será la imagen principal,
  * eliminar imágenes.
- Cada producto puede conservar hasta 12 imágenes en total.
- En la ficha del producto aparece una galería de miniaturas.
- Al pasar el mouse sobre la imagen principal en computadora se activa un zoom siguiendo la posición del cursor.
- En móviles se muestran las miniaturas, pero el zoom por hover se desactiva.

IMPORTANTE:
- Mantén tu mismo .env.
- Puedes copiar tu carpeta server/data de la versión anterior.
- Ejecuta npm install dentro de server antes de npm start.
