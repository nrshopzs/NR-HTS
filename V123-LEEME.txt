Niños Rancios — V123 · Brevo + correos automáticos

Base estable: V122.

Novedades de V123:
- Integración SMTP con Brevo mediante Nodemailer.
- Correo automático al cliente cuando se crea/confirma un pedido.
- Aviso automático interno a la tienda cuando entra un pedido.
- Correos adaptados para Mercado Pago, Stripe, PayPal, transferencia y contraentrega.
- Transferencia: el correo del cliente incluye los datos bancarios disponibles.
- Avisos al cliente cuando el panel cambia el pedido a Pagado, Enviado, Entregado o Cancelado.
- Formulario de contacto real: envía el mensaje a la tienda y una confirmación automática al cliente.
- Protección básica anti-spam/rate-limit en el formulario.
- Registro persistente de correos de pedido enviados para evitar duplicados por webhooks/reintentos.
- Endpoint seguro de estado: GET /api/email/config (no expone contraseñas ni claves).

No se modificó la lógica de cobro ni validación de:
- Mercado Pago.
- Stripe.
- PayPal.
- Transferencia bancaria.
- Pago contra entrega.

IMPORTANTE PARA USAR V123:
1. Copia tu server/.env de V122 a V123/server/.env.
2. Agrega las variables BREVO_* y STORE_NOTIFICATION_EMAIL indicadas en server/.env.example.
3. No compartas BREVO_SMTP_KEY ni la subas a repositorios públicos.
4. Ejecuta dentro de server: npm install
5. Después: npm start
6. Abre http://localhost:4242/api/email/config y confirma que "configured" sea true.
7. Prueba primero el formulario de contacto.
8. Después haz un pedido de prueba y verifica el correo del cliente y el aviso interno.

Nota sobre el dominio:
Brevo trabaja con la forma técnica Punycode del dominio niñosrancios.com:
xn--niosrancios-2db.com

ImprovMX sigue encargado de la recepción/reenvío de contacto@, pedidos@ y cuentas@.
