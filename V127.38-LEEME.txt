Niños Rancios — V127.38
Corrección: código promocional inválido no bloquea el pago.

Cambios:
- Si un cliente aplica un código promocional inexistente, vencido o no aplicable, el checkout muestra el mensaje de error en rojo pero el código deja de considerarse activo.
- El cliente puede continuar a Mercado Pago, PayPal, Stripe, transferencia o contraentrega sin borrar manualmente el código.
- Un código válido sigue aplicándose normalmente.
- Si la validación de promociones no puede comunicarse con el servidor, el código NO se descarta automáticamente para evitar cobrar sin un descuento que quizá sí era válido.
- Se mantiene la validación del lado del servidor; únicamente se corrigió el estado del checkout para no enviar cupones ya rechazados.

Base: V127.37.
