NIÑOS RANCIOS — V119 · TRANSFERENCIA BANCARIA

Base: V118 PayPal Webhook completa.

NUEVO
- Transferencia bancaria funcional desde checkout.
- Configuración editable desde Administración > Transferencia bancaria.
- Banco, titular, CLABE, número de cuenta, tarjeta opcional, plazo e instrucciones.
- Pedido se crea como "Pendiente de pago".
- El número de pedido se usa como referencia de transferencia.
- El inventario se reserva/descuenta al crear el pedido para evitar sobreventa.
- Si un pedido pendiente por transferencia se cambia a "Cancelado", el inventario reservado se devuelve automáticamente.
- Cliente puede subir comprobante JPG, PNG, WEBP o PDF (máximo 8 MB).
- Los comprobantes se guardan dentro de server/data/transfer-proofs y NO dentro de la carpeta pública del sitio.
- El cliente puede subir/reemplazar comprobante desde la pantalla posterior al pedido y desde Búsqueda de pedidos.
- Administración muestra si existe comprobante y permite abrirlo.
- Botón "Marcar como pagado" para confirmar manualmente la transferencia.
- Al confirmar el pago, el pedido pasa a "Pagado" sin descontar el inventario una segunda vez.

CONFIGURACIÓN
1. Ejecuta la tienda normalmente.
2. Entra al panel privado.
3. Abre "Transferencia bancaria".
4. Captura los datos bancarios.
5. Activa "Transferencia bancaria" y guarda.
6. Haz una compra de prueba seleccionando Transferencia bancaria.

IMPORTANTE
- Verifica el depósito directamente en tu banco antes de pulsar "Marcar como pagado".
- No necesitas poner datos bancarios en .env; se administran desde el panel.
- Si el cliente no paga, cambia el pedido a "Cancelado" para liberar el inventario reservado.
