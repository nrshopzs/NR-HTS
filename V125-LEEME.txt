NIÑOS RANCIOS — V125 · CENTRO DE CORREO

Base: V124.
V123/V124 se conservan como respaldo estable hasta validar esta versión.

NOVEDADES V125
- Editor visual de correo ampliado.
- Logo configurable para los emails (JPG, PNG o WEBP).
- Opción para mostrar u ocultar el logo.
- Opción para mostrar u ocultar el nombre de marca.
- Opción para mostrar u ocultar el pie de página.
- Tamaño y alineación del logo configurables.
- Alineación del encabezado y ancho máximo del email configurables.
- Tipografía seleccionable.
- Colores independientes: encabezado, título, botón, texto del botón, fondo exterior, contenido y texto.
- Centro de correo dentro del panel administrativo.
- Redacción manual de emails desde el panel con formato básico.
- Remitente seleccionable: contacto, pedidos o cuentas.
- Posibilidad de vincular un pedido para cargar automáticamente el email del cliente.
- Variables de pedido disponibles en mensajes manuales.
- Vista previa antes de enviar.
- Historial de correos manuales enviados desde el panel.
- El logo se adjunta embebido (CID) en los correos para no depender de una URL pública durante las pruebas.

PRUEBA RECOMENDADA
1. Copia server/.env desde V124.
2. Ejecuta npm install y npm start dentro de server.
3. Entra al panel privado > Correos.
4. En “Plantillas y diseño”, sube un logo y prueba mostrar/ocultar “Nombre de marca”.
5. Guarda y realiza un pedido/cambio de estado para verificar el correo automático.
6. En “Redactar correo”, envía un mensaje manual a un correo de prueba.
7. Revisa el historial de correos manuales.

No se modificó la lógica de Mercado Pago, Stripe, PayPal, transferencia ni contraentrega.
