NIÑOS RANCIOS — V124 · EDITOR DE PLANTILLAS DE CORREO
========================================================

Base: V123 (Brevo SMTP + correos automáticos ya validados).
V123 permanece como respaldo estable hasta que V124 sea probada.

NOVEDAD PRINCIPAL
-----------------
El panel administrativo incorpora una nueva sección:

  Plantillas de correo

Desde ahí puedes editar sin tocar email.js:
- Nombre de marca mostrado en los correos.
- Color principal y color de fondo.
- Pie de página.
- URL de la tienda.
- Asunto, título y mensaje de cada tipo de correo.
- Texto y enlace de botón opcional.
- Vista previa inmediata antes de guardar.

PLANTILLAS EDITABLES
--------------------
- Pedido confirmado · pago aprobado
- Pedido recibido · transferencia pendiente
- Pedido confirmado · contra entrega
- Aviso interno · nuevo pedido
- Estado · pagado
- Estado · enviado
- Estado · entregado
- Estado · cancelado
- Contacto · confirmación al cliente
- Contacto · aviso interno

Las configuraciones se guardan en:
  server/data/email-templates.json

No se guardan claves SMTP ni secretos en ese archivo.
Las credenciales de Brevo continúan únicamente en server/.env.

PRUEBA RECOMENDADA
------------------
1. Copia el server/.env de V123 a V124/server/.env.
2. Abre V124/server en PowerShell.
3. Ejecuta: npm install
4. Ejecuta: npm start
5. Entra al panel administrativo por la ruta privada configurada.
6. Abre “Plantillas de correo”.
7. Cambia temporalmente un título y guarda.
8. Haz una compra de prueba o cambia el estado de un pedido para comprobar el correo.
9. Verifica también el formulario de contacto.

Si todo funciona, V124 puede reemplazar a V123 como base estable.
