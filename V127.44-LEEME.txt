NIÑOS RANCIOS V127.44 — WASMER STAGING / RAÍZ DE ZIP CORREGIDA

Base: V127.43 — Compatibilidad Wasmer / Staging.

CAMBIO ÚNICO PRINCIPAL
- El ZIP de entrega coloca package.json, server.js, public/ y server/ directamente en la raíz del archivo comprimido.
- Esto evita que el constructor node-base de Wasmer busque /opt/build/package.json mientras el proyecto está encerrado dentro de una carpeta contenedora.

SEGURIDAD
- NO se incluye ningún archivo .env real.
- .env.example se conserva únicamente como plantilla.
- Las credenciales (Brevo, pagos, administración, etc.) deben configurarse como variables de entorno del hosting y no dentro del ZIP.

FUNCIONALIDAD
- No se modifica el frontend ni la lógica comercial respecto de V127.43.
- Se preservan las correcciones de seguridad de V127.41 y la capa PostgreSQL de V127.42.
- Se conserva la compatibilidad con DATABASE_URL y con DB_HOST/DB_PORT/DB_NAME/DB_USERNAME/DB_PASSWORD de Wasmer.

CONFIGURACIÓN WASMER PARA LA PRIMERA PRUEBA
Tipo detectado: node-base / QuickJS
Comando de Inicio: npm start
Comando de Construcción: vacío
Comando de Instalación: npm install
Variables iniciales:
  NODE_ENV=production
  DATA_BACKEND=json
Base de datos: desactivada durante la primera prueba de arranque.

Después de confirmar que la tienda inicia correctamente en Wasmer, se activa PostgreSQL y se cambia DATA_BACKEND=postgres.
