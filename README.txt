NIÑOS RANCIOS — TIENDA V3 (MULTIPÁGINA)

Esta versión parte de ninos-rancios-tienda-v2 y amplía la maqueta a todas las páginas principales del sitio Wix de referencia.

Páginas incluidas:
- index.html — Home
- shop-all.html — Tienda con filtros visuales
- woman.html
- men.html
- about-us.html
- contact.html
- product.html — ficha dinámica de producto (?id=...)
- privacy.html
- shipping.html
- returns.html
- order-lookup.html
- offers.html
- partners.html

También incluye:
- Header y footer compartidos en todas las páginas.
- Hombreú desplegable Tienda > Mujer / Hombre.
- Carrito visual con localStorage.
- Diseño responsivo para móvil.
- Imágenes de referencia enlazadas desde los recursos públicos del sitio Wix para acercar la apariencia a la plantilla.

IMPORTANTE:
1. Es una maqueta front-end; no procesa pagos ni pedidos reales.
2. Los textos legales son deliberadamente de ejemplo y deben sustituirse antes de publicar.
3. Los recursos de imagen remotos requieren conexión a internet. Para una versión final conviene reemplazarlos por fotos propias de los 8 diseños de Niños Rancios.
4. Para probar localmente, abre index.html. Para un funcionamiento idéntico a hosting, se recomienda servir la carpeta con un servidor local (por ejemplo VS Code Live Server).
