V116 — STRIPE PREPARADO PARA PASAR DE PRUEBA A PRODUCCIÓN

Base: V115 completa.

Cambios:
- La clave publicable de Stripe puede configurarse desde server/.env.
- Nuevo endpoint público /api/stripe/config que entrega solo configuración segura para Stripe.js.
- Detección automática test/live.
- Validación para evitar mezclar claves test y live.
- El checkout muestra automáticamente si Stripe está en prueba o en modo real.
- El mensaje de procesamiento deja de decir “prueba” cuando se usan claves live.
- /api/stripe/status informa estado de clave publicable y webhook sin exponer secretos.
- Mensajes de arranque más claros para detectar configuración incompleta.
- Se conserva el webhook firmado y el flujo de finalización idempotente existente.

No se incluyeron claves live ni secretos en el ZIP.
